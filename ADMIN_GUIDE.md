# Руководство администратора GetGrant

## Вход в админ-панель

### Данные для входа:
- **URL**: `http://localhost:8001/admin`
- **Email**: `admin@getgrant.com`
- **Пароль**: `admin123`

## Функционал админ-панели

### 1. Управление пользователями (`/admin/users`)

#### Создание менеджера:
1. Перейдите в раздел "Пользователи"
2. Нажмите "Создать"
3. Заполните:
   - Имя
   - Email
   - Роль: выберите "Менеджер"
   - Пароль
4. Сохраните

#### Создание студента:
1. Перейдите в раздел "Пользователи"
2. Нажмите "Создать"
3. Заполните:
   - Имя
   - Email
   - Роль: "Студент"
   - Тип профиля: "Студент"
   - Менеджер: выберите менеджера из списка
4. Сохраните

#### Привязка родителя к студенту:
1. Найдите родителя в списке пользователей
2. Нажмите "Редактировать"
3. В поле "Ребенок (для родителей)" выберите студента
4. Сохраните

#### Назначение админа:
1. Найдите пользователя в списке
2. Нажмите "Редактировать"
3. Измените роль на "Администратор"
4. Сохраните

**Важно**: Только главный админ может назначать других админов. Обычные админы не могут изменять роли других админов.

### 2. Управление контентом

#### Страны (`/admin/countries`)
- Создание, редактирование, удаление стран
- Загрузка флагов и изображений
- Добавление selling points

#### Университеты (`/admin/universities`)
- Управление партнерскими университетами
- Добавление описаний, стоимости, требований
- Загрузка логотипов

#### Программы (`/admin/programs`)
- Управление программами поступления
- Отметка топовых программ
- Добавление информации о карьере

#### Курсы (`/admin/courses`)
- Создание курсов подготовки
- Настройка типов курсов (IELTS, SAT, English и т.д.)

#### Уроки (`/admin/lessons`)
- Просмотр всех уроков
- Редактирование и удаление

#### Категории (`/admin/categories`)
- Управление категориями уроков
- Создание новых категорий

### 3. Управление документами

#### Документы (`/admin/documents`)
- Загрузка лицензий и сертификатов
- Управление типами документов

#### Документы пользователей (`/admin/user-documents`)
- Просмотр загруженных документов студентов
- Проверка статусов документов

### 4. Управление заявками

#### Заявки (`/admin/applications`)
- Просмотр всех заявок на поступление
- Изменение статусов
- Управление таймлайном

#### Лиды (`/admin/leads`)
- Просмотр всех лидов
- Назначение менеджеров


## Создание первого админа через команду

```bash
docker exec -it getgrant2_app bash
php artisan db:seed --class=AdminSeeder
```

Или через tinker:
```bash
php artisan tinker
>>> User::create([
    'name' => 'Администратор',
    'email' => 'admin@getgrant.com',
    'password' => Hash::make('admin123'),
    'role' => 'admin',
    'profile_type' => 'student',
    'email_verified_at' => now(),
]);
```

## Важные замечания

1. **Безопасность**: После первого входа смените пароль админа
2. **Менеджеры**: Создаются только через админ-панель, не через регистрацию
3. **Родители**: Привязываются к студентам только через админ-панель
4. **Автоматическое назначение**: При регистрации студента или родителя автоматически назначается менеджер с наименьшей нагрузкой
